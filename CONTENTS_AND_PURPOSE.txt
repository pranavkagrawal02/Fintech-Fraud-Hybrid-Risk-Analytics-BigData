What Is In This Folder and Why

Project name: fraudlens-mongo-spark-hybrid (use this as your GitHub repository name). Goal: finish BITS
Assignment 2 (Big Data Systems) with Scenario 6 (Fintech fraud), Track C (hybrid MongoDB + PySpark), doing the
least possible work inside the lab.

Start here

1.  Read docs/STEP_BY_STEP_PLAN.md (or .txt).
2.  Do the laptop steps, zip the folder, upload to the lab.
3.  Run the scripts, take the screenshots listed in docs/SCREENSHOT_CHECKLIST.md.
4.  Paste them into report/Assignment2_Report_Template.docx.

Things to know about this package

-   Tested here: the data-preparation script (it ran and produced valid nested documents), Python and shell
    syntax, JavaScript syntax, and the Word report rendering.
-   Not tested here: anything that needs your MongoDB or Spark cluster (steps 03 to 08). I did not have access
    to a cluster. Expect to adjust small things (connection URI, connector jar); see docs/TROUBLESHOOTING.md.
-   The device, geography, merchant-category and timestamp fields are SYNTHETIC enrichment. Fraud rows are
    deliberately more likely to use shared devices and unusual locations. Model scores will therefore look
    better than on real data - say this in your report (the template already has a place for it).
-   The report text is a draft. The numbers, observations and discussion must come from your own runs.
-   I do not know the grading rubric. The plan maps the work to the learning outcomes listed in the assignment
    PDF.
